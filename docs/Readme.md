# AI Developer Assistant

一个基于 Vue3 + FastAPI + LLM 的 AI 开发助手。

## Tech Stack

### Frontend
- Vue3
- TypeScript
- Pinia
- Vue Router
- Element Plus

### Backend
- FastAPI
- Python 3.12

### AI
- OpenAI Compatible API

## Features

- Chat
- Code Analysis
- Prompt Optimization
- Project Assistant

## Run

### Frontend

npm install
npm run dev

### Backend

source .venv/bin/activate
uvicorn main:app --reload
